This project predicts house prices using machine learning regression models.

## Approach

- Data loading
- Exploratory Data Analysis
- Feature analysis
- Linear Regression
- Random Forest Regression
- Model evaluation
- Streamlit deployment

## Models Used

1. Linear Regression
2. Random Forest Regressor

## Evaluation Metrics

- RMSE
- R² Score

## Deployment

The final model is deployed using Streamlit.
